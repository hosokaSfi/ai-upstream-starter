## 3. ストーリー詳細(例: US-301)

- **ストーリー**: 従業員として、有給の残日数を確認しながら休暇申請をしたい。取りすぎ・二重申請を防ぎたいから
- **対応機能ID**: F-005 / **エピック**: E-02
- **SP**: 5(根拠: 画面+API 2本+残日数引当ロジック。複雑度中・不確実性低)
- **依存**: US-103(認証)、US-104(テナントガード)

**受入条件**

- [ ] Given ログイン済み従業員 When 休暇申請画面を開く Then 有給残日数が表示される
- [ ] Given 残日数2日 When 3日間の申請を送信 Then E-BIZ-021エラーで登録されない
- [ ] Given 同一日に承認待ち申請あり When 同じ日で再申請 Then 重複エラーになる
- [ ] Given 申請成功 When 承認者がメールを確認 Then 承認依頼通知が届いている(US-601連携)
- [ ] 異常系: Given 承認ルート未設定の部署 When 申請 Then 管理者に設定を促すエラーが出る

**設計参照**: BD-001 §5.1 UC-02 / DB-001 requests, leave_balances
