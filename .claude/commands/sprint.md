sprint-ops スキルを使ってスプリント運営を支援してください。

指定: $ARGUMENTS

- `plan` → スプリント計画(キャパ計算・ゴール提案・タスク分解)
- `refine` → バックログリファインメント(分割案・受入条件改善・設計との不整合検出)
- `review` → スプリントレビュー資料・デモ手順・サマリ作成
- `retro` → レトロ支援(実績整理・パターン分析・ベロシティ更新→納期予測更新を促す)
- `daily` → Issues/PRから状況サマリ生成
- 指定なし → 現在のスプリント状況を確認し、どれが必要か提案する
