## 1. 可用性

| 項目 | 要件 | 備考 |
|---|---|---|
| 稼働時間 | 例: 24時間365日 / 平日9-18時 | |
| 目標稼働率 | 例: 99.5%(月間ダウン約3.6時間まで) | |
| 計画停止 | 例: 月1回・深夜2時間まで許容 | |
| RTO(目標復旧時間) | 例: 4時間 | 障害発生から復旧まで |
| RPO(目標復旧時点) | 例: 24時間(日次バックアップ) | 失ってよいデータの期間 |

## 2. 性能・拡張性

| 項目 | 要件 | 備考 |
|---|---|---|
| 同時接続ユーザー数 | 例: 通常50 / ピーク200 | ピーク時期も明記(月末等) |
| 画面応答時間 | 例: 通常操作2秒以内(90%tile) | |
| API応答時間 | 例: 500ms以内(95%tile) | |
| バッチ処理時間 | 例: 日次バッチは6時までに完了 | |
| データ増加への対応 | 例: 3年間はスキーマ変更なしで運用可能 | |

## 3. 運用・保守性

| 項目 | 要件 |
|---|---|
| 監視 | 何を監視し、誰にどう通知するか |
| バックアップ | 対象・頻度・保持期間・リストア試験の頻度 |
| ログ保持 | 種類ごとの保持期間(例: アクセスログ1年) |
| メンテナンス体制 | 障害時の一次対応者、対応時間帯 |

## 4. 移行性

| 項目 | 要件 |
|---|---|
| 既存データ移行 | 対象データ・件数・移行方式・リハーサル要否 |
| 並行稼働 | 旧システムとの並行稼働期間の有無 |

## 5. セキュリティ

| 項目 | 要件 |
|---|---|
| 認証 | 例: メール+パスワード、パスワードポリシー、MFA要否 |
| 認可 | ロールベースアクセス制御(ロール一覧は要件定義書参照) |
| 通信の暗号化 | TLS1.2以上必須 |
| 保存データの暗号化 | DB・ストレージの暗号化要否 |
| 個人情報の扱い | 保有する個人情報の種類、マスキング・削除要件 |
| 監査ログ | 誰がいつ何をしたかの記録範囲・保持期間 |
| 脆弱性対応 | 診断の実施要否・頻度、依存パッケージ更新方針 |

## 6. システム環境

| 項目 | 要件 |
|---|---|
| 対応ブラウザ | 例: Chrome / Edge / Safari 最新版 |
| 対応デバイス | 例: PC必須、スマホ対応はSHOULD |
| 多言語対応 | 例: 日本語のみ |
| アクセシビリティ | 目標レベル(例: WCAG 2.1 A) |
