## 1. API共通規約

| 項目 | 規約 |
|---|---|
| ベースURL | 例: `https://api.example.com/api/v1` |
| 認証 | 例: `Authorization: Bearer {JWT}` |
| Content-Type | `application/json` |
| 命名 | リソースは複数形・ケバブケース(例: `/leave-requests`) |
| 日時形式 | ISO 8601(UTC)例: `2026-07-17T00:00:00Z` |
| ページネーション | `?page=1&per_page=20`、レスポンスに `total_count` |
| ソート | `?sort=-created_at`(`-`降順) |

### 1.1 ステータスコード規約

| コード | 用途 |
|---|---|
| 200 / 201 / 204 | 成功(取得 / 作成 / 削除) |
| 400 | バリデーションエラー |
| 401 | 未認証 |
| 403 | 権限なし |
| 404 | リソースなし |
| 409 | 競合(重複登録・楽観ロック失敗) |
| 500 | サーバエラー |

### 1.2 エラーレスポンス共通形式

```json
{
  "error": {
    "code": "E-VAL-001",
    "message": "入力内容に誤りがあります",
    "details": [
      { "field": "email", "message": "メールアドレスの形式が正しくありません" }
    ]
  }
}
```
